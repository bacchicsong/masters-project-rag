# Прогресс к чекпоинту №3

**hybrid-retriever.py** содержит реализацию различных стратегий взаимодействия BM25 + bi-encoder отбора релевантных документов к вопросу. Выполнил Охотин Даниил

**rag-system.py** содержит тестовый вариант подгрузки в генеративную модель контекста и генерации ей ответа. Выполнил Охотин Даниил

**bi_encoder.py** содержит реализацию Bi-Encoder и тестовый пример на mock-данных. Выполнил Гусев Владислав
